Definition

What is Web 2.0 Gloss?

The growth of interactive web applications brought a cheerful, polished visual language. The aesthetic suggested that software could be approachable, social, and easy to use.

Visual recognition

Typical elements

Use these recurring characteristics as recognition clues rather than a checklist that every example must satisfy.

  • Glossy buttons
  • Strong gradients
  • Reflections and highlights
  • Rounded corners
  • Large friendly logos
  • Bright lime, orange, cyan, and blue accents
  • Oversized sans-serif headings
  • Starbursts and “beta” badges
  • Soft drop shadows
  • Large call-to-action buttons
  • White backgrounds with generous spacing
  • Ajax interactions that updated content without reloading the page
