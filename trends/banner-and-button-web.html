Banner-and-Button Web

Definition

What is Banner-and-Button Web?

Small graphic assets became a basic visual vocabulary of the early web. Buttons often communicated identity, software allegiance, community membership, or technical capability as much as navigation.

Visual recognition

Typical elements

Use these recurring characteristics as recognition clues rather than a checklist that every example must satisfy.

  • Rectangular banner advertisements
  • Compact 88×31 affiliation or technology badges
  • Graphical navigation buttons
  • “Made with…” and browser-compatibility badges
  • Award icons
  • Download buttons
  • Repeated animated promotional graphics
  • Beveled edges and high-contrast text
