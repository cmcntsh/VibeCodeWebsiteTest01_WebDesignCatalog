Definition

What is Responsive Web Design?

Ethan Marcotte named and formalized responsive web design in 2010. Its foundational techniques were flexible grids, flexible images, and CSS media queries. Responsive design is primarily an architectural method rather than an aesthetic, but it profoundly changed the appearance and organization of websites.

Visual recognition

Typical elements

Use these recurring characteristics as recognition clues rather than a checklist that every example must satisfy.

  • Layouts that reflow at defined breakpoints
  • Flexible images and media
  • Columns stacking on small screens
  • Navigation transforming for mobile
  • Type and spacing adjusted by viewport size
  • Touch-friendly controls
  • Content prioritization
  • One codebase serving multiple device classes
