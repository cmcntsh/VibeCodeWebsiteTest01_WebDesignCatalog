Guided learning

Use the catalog as a teaching and study tool.

The catalog supports quick identification, chronological exploration, side-by-side comparison, and deeper historical reading.

For beginners
Plain-language definitions and visual specimens
For educators
Stable pages, print styles, citations, and sequences
For researchers
Aliases, ranges, relationships, and source notes

Four learning paths

Begin with a question, not a syllabus.

Each path links a small sequence of entries that demonstrates a useful historical or visual relationship.

01

Recognize an unfamiliar style

Start with a visual description, open the best matching entry, then compare related movements.

  1. WDTC–0017 — Web 2.0 Gloss
  2. WDTC–0018 — Reflective Floors and Aqua Interfaces
  3. WDTC–0020 — Skeuomorphism
  4. WDTC–0027 — Flat Design
  5. WDTC–0034 — Flat 2.0 or Semi-Flat Design
02

Teach the early web

Move from document-style pages to personal homepages, buttons, frames, tables, and contemporary webcore revival.

  1. WDTC–0001 — Text-Only or Document-Style Web
  2. WDTC–0002 — Personal Homepage Vernacular
  3. WDTC–0007 — Banner-and-Button Web
  4. WDTC–0008 — Frame-Based Design
  5. WDTC–0005 — Table-Based Layout
  6. WDTC–0054 — Retro Web and Webcore Revival
03

Trace a reaction cycle

Follow tactile realism into flat reduction, then into moderated depth and new forms of digital tactility.

  1. WDTC–0020 — Skeuomorphism
  2. WDTC–0027 — Flat Design
  3. WDTC–0034 — Flat 2.0 or Semi-Flat Design
  4. WDTC–0047 — Neumorphism
  5. WDTC–0048 — Glassmorphism
  6. WDTC–0049 — Claymorphism and Soft 3D
04

Understand responsive architecture

Study the shift from fixed and fluid layout to responsive, mobile-first, modular, and component-driven systems.

  1. WDTC–0005 — Table-Based Layout
  2. WDTC–0014 — Liquid or Fluid Layout
  3. WDTC–0022 — Fixed-Width 960-Grid Design
  4. WDTC–0025 — Responsive Web Design
  5. WDTC–0026 — Mobile-First Design
  6. WDTC–0029 — Card-Based Design
  7. WDTC–0059 — Design-System and Component-Driven Aesthetics
A

Search naturally

Describe the appearance you remember. The search index includes common names and typical elements, not only official titles.

B

Compare carefully

Use the comparison tool to distinguish related terms such as Aqua, Web 2.0 gloss, glassmorphism, and skeuomorphism.

C

Cite responsibly

Popularity ranges are approximate. Image labels distinguish representative reconstructions from archival evidence.
