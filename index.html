Explore by era

Four decades. No clean borders.

Follow the medium from linked documents and personal pages to responsive systems, revivals, and adaptive interfaces.

1991–1999

The Web Finds a Visual Language

Document-style pages, personal homepages, tables, frames, portals, buttons, pixel graphics, Flash intros, and cyber futurism establish the first recognizable web aesthetics.

2000–2009

Polish, Standards, and Rich Interfaces

CSS standards, blogs, glossy application interfaces, tactile materials, editorial grids, Flash experiences, and early responsive thinking reshape the medium.

2010–2019

Responsive Systems Become the Default

Mobile-first architecture, flat design, cards, Material Design, large photography, bold type, motion, and component systems redefine mainstream interface design.

2020–present

Revival, Expression, and Adaptive Production

Glass, clay, neo-brutalism, bento grids, retro revivals, experimental type, no-code systems, and AI-assisted interfaces coexist in a highly plural web.

How the catalog works

Built for learning, teaching, and research.

Start with a quick definition, then move into visual evidence, terminology, comparison, and source notes.

01

Search in ordinary language

You do not need to know “skeuomorphism” before searching. Try descriptions such as “realistic notebook UI,” “frosted panels,” or “clashing old web.”

02

Follow relationships

Trace reactions, revivals, and nearby movements. Compare rich realism with flat reduction, or authentic early-web conventions with webcore reinterpretations.

03

Use it as a reference

Stable URLs, common names, print styles, image labels, and copyable citations support lessons, articles, and independent research.
